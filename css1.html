CSS Lesson 1 — Selectors

Estimated time: 20–35 minutes · Level: Beginner

Overview

Selectors target elements in the DOM so you can apply styles. This lesson covers the most common selector types, how they combine, and rules that determine which styles win when multiple rules match the same element.

Basic selectors

Start with simple selectors that match elements by type, class, id, or universal match.

  • element — selects all elements of that type (for example p).
  • .class — selects elements with the given class.
  • #id — selects the element with the given id (unique per page).
  • * — universal selector (matches any element).
/* type selector */
p { margin-bottom: 1rem; }

/* class selector */
.card { padding: 12px; border-radius: 8px; }

/* id selector */
#site-title { font-weight: 800; }

/* universal selector */
* { box-sizing: border-box; }
Tip: Prefer classes for reusable styling; reserve IDs for unique, scriptable hooks when necessary.

Combinators

Combinators describe relationships between elements.

  • A B (descendant) — selects B inside A at any depth.
  • A > B (child) — selects B that are direct children of A.
  • A + B (adjacent sibling) — selects B immediately following A.
  • A ~ B (general sibling) — selects B that follow A as siblings.
/* descendant */
nav a { color: #00aaff; }

/* child */
ul > li { list-style: none; }

/* adjacent sibling */
h2 + p { margin-top: 0.25rem; }

/* general sibling */
h3 ~ p.note { color: #bfcbdc; }

Attribute and pseudo selectors

Attribute selectors match elements with specific attributes. Pseudo-classes and pseudo-elements target states or parts of elements.

/* attribute selectors */
a[target="_blank"] { text-decoration: underline; }
input[type="email"] { width: 100%; }

/* pseudo-classes */
a:hover { opacity: 0.9; }
input:focus { outline: 2px solid #00aaff; }

/* pseudo-elements */
p::first-line { font-weight: 700; }
button::after { content: " ↗"; }
Use cases

Use :focus to improve keyboard accessibility and [attr] selectors to style elements based on attributes without extra classes.

Specificity and cascade

When multiple rules match an element, the browser uses specificity and source order to decide which rule applies.

Specificity rules (simplified)

  • Inline styles (style="") have highest specificity.
  • ID selectors count more than class/attribute/pseudo-class selectors.
  • Class, attribute, and pseudo-class selectors are next.
  • Type selectors and pseudo-elements are lowest.
  • If specificity ties, the later rule in the stylesheet wins.
/* example: which color applies? */
p { color: blue; }           /* type selector (low) */
.note { color: green; }      /* class selector (higher) */
#intro { color: red; }       /* id selector (highest) */

/* result: element with id="intro" and class="note" will be red */
Rule: Keep specificity low and predictable by using classes and avoiding deep selector chains.

Examples

Simple card component

.card {
  background: #071428;
  border: 1px solid rgba(255,255,255,0.04);
  padding: 16px;
  border-radius: 8px;
}

.card .title { font-size: 1.1rem; font-weight: 700; }
.card .meta { color: #9fb6d6; font-size: 0.9rem; }

Responsive utility selectors

/* mobile-first */
.container { padding: 16px; }

@media (min-width: 800px) {
  .container { max-width: 900px; margin: 0 auto; }
}
Practice: Create a small HTML file with several elements and try the selectors above. Inspect matched rules in DevTools to see specificity and cascade in action.
