CSS Lesson 2 — Box Model

Estimated time: 20–35 minutes · Level: Beginner
Back to Lessons

Overview

The CSS box model defines how elements occupy space: content, padding, border, and margin. Understanding the box model is essential for layout, spacing, and sizing behavior.

Box model components

From the inside out:

  • Content — the element's text or child elements; width/height apply here by default.
  • Padding — space between content and border; increases the element's visual size.
  • Border — visible edge around padding/content; adds to the element's size.
  • Margin — space outside the border; separates elements from each other.

padding 8px · border 4px · margin 6px

Box-sizing

The box-sizing property controls whether width/height include padding and border.

/* default: width/height apply to content box */
.box-default { box-sizing: content-box; width: 200px; padding: 16px; border: 4px solid #00aaff; }

/* recommended: include padding and border in width/height */
.box-border { box-sizing: border-box; width: 200px; padding: 16px; border: 4px solid #00aaff; }
Recommendation: Use *, *::before, *::after { box-sizing: border-box; } to make sizing predictable across components.

Margin collapsing

Adjacent vertical margins between block-level elements can collapse into a single margin equal to the largest margin. This often surprises developers when spacing appears smaller than expected.

<div class="a"></div>
<div class="b"></div>

/* if .a has margin-bottom:20px and .b has margin-top:30px,
   the resulting space between them is 30px (the larger), not 50px. */
Avoiding collapse

Use padding, borders, or overflow (for example overflow:auto) on a parent to prevent margin collapse when needed.

Layout impact

Box model choices affect layout, wrapping, and alignment. Padding and borders increase the element's visual footprint (unless using border-box), while margins control spacing between elements. When building responsive layouts, prefer flexible units (%, rem) and predictable box-sizing.

Common pitfalls

  • Unexpected overflow when padding/border push content beyond container width.
  • Margin collapse causing inconsistent vertical spacing.
  • Using fixed widths without accounting for padding/border can break layouts on small screens.

Examples

Global box-sizing reset

/* place early in your stylesheet */
*, *::before, *::after {
  box-sizing: border-box;
}

Card with consistent sizing

.card {
  box-sizing: border-box;
  width: 320px;
  padding: 16px;
  border: 1px solid rgba(255,255,255,0.04);
  border-radius: 8px;
}

Responsive container

.container {
  box-sizing: border-box;
  padding: 16px;
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
}
Practice: Create two boxes with identical width values, one using content-box and the other border-box, and observe how padding and border affect the rendered size.
