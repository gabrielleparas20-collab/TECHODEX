Overview

Colors and backgrounds set tone, hierarchy, and readability. This lesson explains color models, CSS color syntaxes, background properties, gradients, transparency, blending modes, and accessibility considerations for contrast and color usage.

Color models

Common color models used on the web:

  • RGB — additive model using red, green, blue channels.
  • HSL — hue, saturation, lightness; often easier for perceptual adjustments.
  • Hex — compact RGB representation (for example #00aaff).
  • Lab and LCH — perceptually uniform models (supported via color() in modern browsers) for advanced color work.
Tip: Use HSL when you need to adjust lightness or saturation programmatically; use RGB/hex for exact color matches.

Color units and syntaxes

CSS supports multiple syntaxes. Examples:

/* hex */
color: #00aaff;

/* short hex */
color: #0af;

/* rgb / rgba */
color: rgb(0,170,255);
color: rgba(0,170,255,0.85);

/* hsl / hsla */
color: hsl(197, 100%, 53%);
color: hsla(197, 100%, 53%, 0.85);

/* modern color() with display-p3 or lab (browser support varies) */
color: color(display-p3 0.0 0.67 1.0);
When to use alpha

Use alpha channels for overlays, subtle shadows, and layered UI elements. Prefer semi-transparent black/white for overlays to preserve contrast with varied backgrounds.

Background properties

Backgrounds combine color, images, position, repeat, size, and attachment. Key properties:

  • background-color
  • background-image
  • background-position
  • background-size
  • background-repeat
  • background-attachment
  • background-blend-mode
/* shorthand */
.header {
  background: linear-gradient(rgba(0,0,0,0.4), rgba(0,0,0,0.2)),
              url('../images/hero.jpg') center/cover no-repeat;
}

/* separate properties */
.card {
  background-color: #071428;
  background-image: url('pattern.svg');
  background-repeat: repeat;
  background-size: 40px 40px;
}
Performance: Use optimized images and prefer CSS patterns or SVG for small repeating textures to reduce requests and file size.

Gradients

CSS gradients are images generated by the browser. They are useful for subtle depth, overlays, and decorative backgrounds without extra assets.

/* linear gradient */
.hero {
  background: linear-gradient(180deg, #00aaff 0%, #0077aa 100%);
}

/* radial gradient */
.badge {
  background: radial-gradient(circle at 30% 30%, #fff 0%, rgba(255,255,255,0) 40%);
}

/* conic gradient */
.loader {
  background: conic-gradient(from 90deg, #00aaff, #0077aa, #00aaff);
}
Layered gradients

Combine gradients with images to create readable overlays:

.hero {
  background:
    linear-gradient(to bottom, rgba(0,0,0,0.35), rgba(0,0,0,0.6)),
    url('hero.jpg') center/cover no-repeat;
}

Transparency and blending

Alpha channels and blend modes let you create layered visual effects. Use mix-blend-mode and background-blend-mode carefully — they can affect readability and performance.

/* semi-transparent overlay */
.overlay {
  background-color: rgba(0,0,0,0.5);
}

/* blend mode */
.image {
  background-image: url('photo.jpg');
  background-blend-mode: multiply;
}
Accessibility caution: Blending can reduce contrast. Always verify text legibility after applying blend modes or semi-transparent overlays.

Contrast and accessibility

Contrast affects readability for users with low vision. Follow WCAG contrast guidelines: at least 4.5:1 for normal text and 3:1 for large text. Tools and browser extensions can measure contrast ratios.

/* example: high-contrast text */
.button {
  background: #00aaff;
  color: #ffffff; /* check contrast ratio against background */
}
Practical checks
  • Test color combinations with a contrast checker.
  • Provide alternative indicators (icons, underlines) not relying on color alone.
  • Respect user preferences for reduced motion and high-contrast modes.

Examples — practical snippets

Theme variables and light/dark switch

:root {
  --bg: #ffffff;
  --text: #071428;
  --accent: #00aaff;
}

[data-theme="dark"] {
  --bg: #071428;
  --text: #eaf6ff;
  --accent: #00aaff;
}

body {
  background-color: var(--bg);
  color: var(--text);
}

Hero with overlay and responsive image

.hero {
  background:
    linear-gradient(to bottom, rgba(0,0,0,0.25), rgba(0,0,0,0.6)),
    url('hero-1200.jpg') center/cover no-repeat;
  min-height: 60vh;
  display:flex;
  align-items:center;
  justify-content:center;
  color:#fff;
}

Accessible accent and focus state

a { color: var(--accent); }
a:focus, a:hover { outline: 3px solid rgba(0,170,255,0.18); outline-offset: 3px; }
Practice: Create a small palette (primary, secondary, neutral, accent) and build a demo page that switches between light and dark themes using CSS variables.
