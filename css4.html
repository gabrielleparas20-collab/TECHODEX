Overview

Typography shapes readability, hierarchy, and tone. This lesson covers choosing font families, loading web fonts responsibly, core CSS properties (font-size, line-height, letter-spacing, font-weight), responsive techniques, and accessibility considerations for legible text across devices.

Font families and fallbacks

Define a font stack that includes a preferred web font, sensible fallbacks, and a generic family. Generic families are serif, sans-serif, monospace, cursive, and fantasy.

/* example font stack */
body {
  font-family: "Inter", "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
}
Tip: Order fallbacks by similarity (x-height, weight) to reduce layout shifts when the preferred font loads.

Web fonts and loading

Use web fonts (Google Fonts, self-hosted, or variable fonts) carefully. Control rendering behavior with font-display and minimize layout shifts by reserving space for the font.

/* example @font-face with font-display */
@font-face {
  font-family: "MySans";
  src: url("/fonts/mysans.woff2") format("woff2");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

/* use variable font axis */
h1 { font-family: "MySans", system-ui, sans-serif; font-weight: 700; }
font-display options
  • swap — show fallback immediately, swap when font loads.
  • block — short invisible period, then fallback; can cause FOIT (flash of invisible text).
  • optional — prefer system font if network slow.

Key typographic properties

Understand the properties that control text appearance and spacing.

font-size

Prefer relative units (rem, em, clamp()) for scalability and user preferences.

html { font-size: 100%; } /* 16px default in most browsers */
body { font-size: 1rem; } /* equals html font-size */
h1 { font-size: 2rem; }

line-height

Line height improves readability. Use unitless values so the computed height scales with font-size.

p { line-height: 1.6; } /* unitless recommended */

font-weight

Use numeric weights (100–900) and avoid using bold for emphasis alone; combine with color or size for hierarchy.

strong { font-weight: 700; }
.light { font-weight: 300; }

letter-spacing & word-spacing

Adjust spacing subtly for headings or small-caps; avoid large positive tracking on body text.

h2 { letter-spacing: -0.02em; }
.small-caps { letter-spacing: 0.02em; font-variant: small-caps; }

text-rendering & font-smoothing

These are platform-specific; use sparingly and test across devices.

Responsive typography

Scale type across viewports for better hierarchy and legibility. Use fluid techniques with clamp(), viewport units, or modular scales.

/* fluid heading using clamp */
h1 {
  font-size: clamp(1.5rem, 2.5vw + 1rem, 3rem);
}

/* modular scale example */
:root {
  --base: 1rem;
  --scale-ratio: 1.25;
}
h2 { font-size: calc(var(--base) * var(--scale-ratio) * 1.25); }
Accessibility note

Respect user font-size preferences (browser zoom and OS settings). Avoid locking text sizes with absolute pixels for body copy.

Accessibility & best practices

  • Maintain sufficient contrast between text and background (WCAG ratios).
  • Use readable line lengths (45–75 characters per line is a common guideline).
  • Prefer unitless line-height and relative font sizes for scaling.
  • Provide visible focus styles for interactive text (links, buttons).
  • Avoid using text-transform alone to convey meaning; screen readers may not convey case changes.
/* visible focus */
a:focus, button:focus {
  outline: 3px solid rgba(0,170,255,0.18);
  outline-offset: 3px;
}

Practical CSS snippet

/* base typographic system */
:root {
  --base-size: 1rem;
  --base-line: 1.6;
  --scale: 1.25;
}

html { font-size: 100%; }
body {
  font-family: "Inter", system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
  font-size: var(--base-size);
  line-height: var(--base-line);
  color: #eaf6ff;
}

/* headings */
h1 { font-size: 2.25rem; line-height: 1.1; margin-bottom: 0.5rem; }
h2 { font-size: 1.5rem; line-height: 1.2; margin-bottom: 0.5rem; }

/* responsive tweak */
@media (min-width: 900px) {
  h1 { font-size: 3rem; }
}
Practice: Build a small page and experiment with clamp() for headings, test font-display behavior, and verify contrast and line length on mobile and desktop.
