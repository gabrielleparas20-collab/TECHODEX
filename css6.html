Overview

Flexbox is a one-dimensional layout model for arranging items in a row or column. It simplifies alignment, spacing, and distribution of space among items, especially when building responsive components. Use flexbox for toolbars, card rows, navs, and small layout components; combine with grid for two-dimensional layouts.

Flex container

Make an element a flex container with display: flex (row by default) or display: inline-flex. Key container properties:

  • flex-direction — row, row-reverse, column, column-reverse.
  • flex-wrap — nowrap, wrap, wrap-reverse.
  • gap — spacing between items (replaces margin hacks).
  • justify-content — main-axis distribution.
  • align-items — cross-axis alignment for items.
.container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  gap: 12px;
}
Tip: Use gap instead of per-item margins for consistent spacing and simpler responsive behavior.

Flex items

Items inside a flex container can be controlled with item-level properties:

  • order — controls visual order without changing DOM order.
  • flex-grow — how much an item grows relative to others.
  • flex-shrink — how an item shrinks when space is limited.
  • flex-basis — initial main size before free space distribution.
  • align-self — override container's align-items for a single item.
.item {
  flex: 1 1 200px; /* flex-grow:1; flex-shrink:1; flex-basis:200px */
}
.item.fixed {
  flex: 0 0 120px; /* fixed width */
}
.item.priority {
  order: -1; /* appears first visually */
}

Alignment

Alignment in flexbox is powerful and concise. Use these properties to position items along main and cross axes:

  • justify-content — flex-start, center, flex-end, space-between, space-around, space-evenly.
  • align-items — stretch, flex-start, center, flex-end, baseline.
  • align-content — controls multi-line alignment when there is extra cross-axis space.
.header {
  display:flex;
  justify-content: space-between;
  align-items: center;
}
Centering both axes 
.centered {
  display:flex;
  justify-content:center;
  align-items:center;
}

Ordering and sizing

Use order sparingly; prefer DOM order for accessibility and source order reading. For responsive sizing, combine flex-basis with flex-grow and min-width/max-width to avoid overflow.

/* responsive card row */
.card { flex: 1 1 220px; min-width: 180px; max-width: 1fr; }

/* hero layout: sidebar fixed, content flexible */
.sidebar { flex: 0 0 280px; }
.content { flex: 1 1 0; }
Accessibility: Changing visual order with order does not change DOM order; keyboard and screen-reader users follow DOM order. Use order only when it doesn't harm reading flow.

Common patterns

Flexbox shines in small, common UI patterns. A few practical patterns:

  • Horizontal nav — distribute links with justify-content: space-between or gap.
  • Card grid — use wrapping flex with fixed flex-basis to create responsive rows.
  • Sticky footer layout — make page a column flex container and let main grow to push footer down.
  • Toolbar with actions — left-aligned title and right-aligned actions using margin-left: auto on the action group.
/* sticky footer */
.page {
  display:flex;
  flex-direction:column;
  min-height:100vh;
}
.page main { flex: 1 0 auto; }
.page footer { flex-shrink: 0; }

Code snippets

/* simple responsive row */
.row {
  display:flex;
  gap:12px;
  flex-wrap:wrap;
}
.row > * { flex: 1 1 200px; }

/* center content vertically and horizontally */
.center {
  display:flex;
  justify-content:center;
  align-items:center;
  height: 200px;
}
Practice: Build a small demo page with a header, a wrapping card row, and a footer using flexbox. Inspect behavior as you resize the viewport and tweak flex-basis, gap, and min-width.
