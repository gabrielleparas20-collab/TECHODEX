CSS Lesson 7 — Grid

Estimated time: 35–55 minutes · Level: Intermediate

Overview

CSS Grid is a two-dimensional layout system that lets you define rows and columns and place items precisely within that grid. Use Grid for page-level layouts, complex components, and any layout where both axes matter. Combine Grid with Flexbox: Grid for overall structure, Flexbox for internal alignment.

Grid container

Turn an element into a grid container with display: grid or display: inline-grid. Define columns and rows using grid-template-columns and grid-template-rows. Use gap for spacing between tracks.

.container {
  display: grid;
  grid-template-columns: 200px 1fr 300px;
  grid-template-rows: auto 1fr auto;
  gap: 16px;
}
Tip: Use gap instead of margins between grid items for consistent spacing.

Tracks, lines, and areas

Tracks are rows and columns. Lines are the boundaries between tracks and are numbered starting at 1. Named grid areas let you map layout regions with a readable template.

/* named areas */
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

/* assign items */
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
When to use areas

Named areas are great for clear page layouts and for reordering regions at different breakpoints using different templates.

Item placement

Place items explicitly using line numbers, named lines, or area names. Shorthand properties grid-column and grid-row control span and start/end positions.

/* place by line numbers */
.item-a { grid-column: 1 / 3; grid-row: 1 / 2; }

/* shorthand */
.item-b { grid-column: 2 / span 2; /* start at line 2, span 2 columns */ }

/* place by area */
.item-c { grid-area: main; }
Auto-placement: When you don't place items, the grid auto-places them in source order. Use explicit placement for precise layouts.

Alignment in grid

Grid provides powerful alignment controls on both axes. Use justify-items, align-items for item-level defaults, and justify-content, align-content for the grid as a whole. Individual items can override with justify-self and align-self.

.grid {
  justify-items: stretch; /* start, center, end, stretch */
  align-items: start;
  justify-content: center; /* controls grid block within container */
  align-content: start;
}

/* per-item override */
.item { justify-self: center; align-self: end; }
Use case: Center a single item both horizontally and vertically with justify-self: center; align-self: center;.

Responsive grids

Grid adapts well to responsive design. Use fractional units (fr), minmax(), and the repeat() function. The auto-fit and auto-fill patterns with minmax() create fluid, wrapping grids.

/* fluid card grid */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

/* minmax example */
.sidebar {
  grid-template-columns: 240px minmax(320px, 1fr);
}
Practical: Use media queries to switch templates or adjust grid-template-areas for different breakpoints.

Common patterns

  • Two-column layout — sidebar + content with responsive collapse.
  • Holy grail layout — header, footer, left/right sidebars, center content.
  • Card masonry — use dense auto-placement or CSS columns for Pinterest-like layouts.
  • Complex dashboard — grid areas and explicit placement for widgets of varying sizes.
/* holy grail example */
.page {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "left main right"
    "footer footer footer";
}

Examples — practical snippets

Simple responsive card grid

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}
.card { padding: 16px; border-radius: 8px; background: #071428; }

Header + sidebar + main using areas

.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr;
  grid-template-areas:
    "header header"
    "sidebar main";
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
