Lesson 1 — HTML Basics

Estimated time: 25–40 minutes · Level: Beginner
Back to Lessons
Objectives Document Structure Basic Elements Semantic Elements Accessibility Deep Dive Summary Sources

Objectives

  • Understand what HTML is and why it matters.
  • Create a valid minimal HTML document with DOCTYPE, head, and body.
  • Use headings, paragraphs, links, images, and lists.
  • Recognize semantic elements and basic accessibility practices.

Document structure

Every HTML page should start with the HTML5 DOCTYPE and include a root <html> element, a <head> for metadata, and a <body> for visible content. The DOCTYPE ensures browsers render the page in standards mode rather than quirks mode.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width,initial-scale=1">
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <p>This is a minimal HTML document.</p>
  </body>
</html>
Why this matters

The DOCTYPE declaration is the simplest way to ensure consistent parsing and rendering across modern browsers.

Basic elements

Headings and paragraphs

Use <h1>–<h6> to create a logical outline; use <p> for paragraphs.

<h1>Main title</h1>
<h2>Section title</h2>
<p>A paragraph of text.</p>

Links and images

Links use the <a> element with an href attribute. Images use <img> with src and alt attributes — always provide meaningful alt text for accessibility.

<a href="https://example.com">Visit example.com</a>

<img src="images/logo.png" alt="Techodex logo">

Lists

Use ordered (<ol>) and unordered (<ul>) lists for grouped items; list items are <li>.

<ul>
  <li>First item</li>
  <li>Second item</li>
</ul>

Semantic elements

Semantic elements (for example <header>, <nav>, <main>, <article>, <section>, <aside>, <footer>) describe the role of content. They help screen readers, search engines, and future developers understand the page. Prefer semantic elements over generic <div>s when the element's meaning is clear.

<header>
  <h1>Site title</h1>
  <nav>...</nav>
</header>

<main>
  <article>...</article>
</main>

<footer>...</footer>
Tip: Use <main> once per page; it should contain the primary content. Use <article> for self-contained pieces (blog posts, news items).

Accessibility basics

Accessibility starts with semantic HTML. Add alt text for images, use descriptive link text (avoid "click here"), ensure headings form a logical outline, and use form labels (<label for="...">) so assistive technologies can associate labels with inputs.

<label for="email">Email address</label>
<input id="email" type="email" name="email">

These practices make your content usable by more people and improve search engine understanding of your pages.

Deep dive — practical details

Attributes and global attributes

Attributes provide additional information about elements. Many attributes are global (usable on most elements): id, class, title, hidden, data-*, and ARIA attributes like aria-label. Use id for unique identifiers and class for styling or grouping.

<button id="saveBtn" class="btn primary" title="Save changes">Save</button>
<div data-user-id="42">...</div>

Forms — structure and labels

Forms are interactive and require careful labeling. Always associate labels with inputs using the for attribute or by wrapping the input inside the label. Use appropriate input types (email, tel, number) to enable built-in validation and mobile-friendly keyboards.

<form action="/subscribe" method="post">
  <label for="name">Full name</label>
  <input id="name" name="name" type="text" required>

  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>

  <button type="submit">Subscribe</button>
</form>

Images: responsive and accessible

Use srcset and sizes to serve appropriately sized images for different viewports. Always include alt. For decorative images, use an empty alt="" so screen readers skip them.

<img src="photo-800.jpg"
     srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
     sizes="(max-width:600px) 100vw, 600px"
     alt="A person coding at a laptop">

Meta tags and basic SEO

Include a descriptive <title> and a concise meta description. Use language attributes and canonical links when appropriate.

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>About — My Site</title>
  <meta name="description" content="Short description of this page for search engines">
</head>

Responsive basics

Start with the viewport meta tag and design mobile-first. Use flexible layouts (percentages, flexbox) and responsive images to ensure pages adapt to different screens.

<meta name="viewport" content="width=device-width, initial-scale=1">

/* CSS example (mobile-first) */
.container { padding: 16px; }
@media (min-width: 800px) {
  .container { max-width: 900px; margin: 0 auto; }
}
Practice tip: Try converting one of your static pages to be responsive by adding the viewport meta tag and switching fixed widths to percentages or flexbox.

Summary

HTML gives structure and meaning to web content. After mastering the minimal document and basic elements, focus on semantic markup, accessibility, and responsive techniques. These foundations make future styling and interactivity far easier and more robust.
