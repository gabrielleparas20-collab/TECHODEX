Lesson 3 — Links and Images

Estimated time: 25–40 minutes · Level: Beginner
Back to Lesson 2

Overview

This lesson covers anchors (links), URL types and pathing, image markup and accessibility, responsive image techniques, and practical best practices. Links connect documents and resources; images convey visual information and must be marked up for accessibility and performance.

Links (anchor element)

The anchor element <a> creates hyperlinks. The most important attribute is href, which specifies the destination. Use descriptive link text that explains the destination or action.

Basic examples

<a href="https://example.com">Visit Example</a>

<a href="about.html">About this course</a>  <!-- relative link to a page in the same folder -->

<a href="#section-id">Jump to section</a>  <!-- in-page anchor -->

Attributes and behaviors

  • target="_blank" opens the link in a new tab; pair it with rel="noopener noreferrer" for security.
  • rel describes the relationship (for example rel="nofollow" or rel="noopener").
  • Use clear, meaningful link text (avoid "click here").
Open in new tab safely 
<a href="https://example.com" target="_blank" rel="noopener noreferrer">Open Example in new tab</a>

URLs and path types

Links use absolute or relative URLs. Choose the right type depending on where the target lives and whether you plan to move or deploy the site.

Absolute vs relative

  • Absolute URL: full path including protocol (e.g., https://example.com/page.html).
  • Relative URL: path relative to the current document (e.g., about.html, ../index.html, images/photo.jpg).
Relative examples 
<a href="html/html4.html">Lesson 4</a>        <!-- child folder from lessons/index.html -->
<a href="../index.html">Back to Lessons</a>   <!-- from lessons/html/html3.html to lessons/index.html -->

Mailto and telephone links

<a href="mailto:hello@example.com">Email us</a>
<a href="tel:+15551234567">Call support</a>

Images and accessibility

The <img> element embeds images. Always include an alt attribute. The alt text should describe the image's content or purpose; if the image is purely decorative, use an empty alt="" so screen readers skip it.

Basic image markup

<img src="images/logo.png" alt="Techodex logo">

<img src="images/hero.jpg" alt="Students collaborating on laptops">

When to use empty alt

Use alt="" for decorative images (icons, purely visual flourishes) so assistive technologies ignore them. For informative images, provide concise, meaningful descriptions.

Captioning and long descriptions: For complex images (charts, diagrams), provide a short alt and a longer description nearby or via aria-describedby linking to a detailed explanation.

Responsive images

Use srcset and sizes to serve appropriately sized images for different viewports and resolutions. This improves performance and reduces bandwidth on small devices.

<img src="photo-800.jpg"
     srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
     sizes="(max-width:600px) 100vw, 600px"
     alt="A person coding at a laptop">

Picture element for art direction

<picture>
  <source media="(max-width:600px)" srcset="hero-small.jpg">
  <source media="(min-width:601px)" srcset="hero-large.jpg">
  <img src="hero-large.jpg" alt="Hero image description">
</picture>

Best practices

  • Write descriptive link text that stands alone out of context.
  • Use rel="noopener noreferrer" with target="_blank".
  • Provide meaningful alt text for images; use empty alt="" for decorative images.
  • Use responsive images to optimize performance.
  • Prefer relative links for internal navigation so the site remains portable.

Summary

Links and images are fundamental building blocks of the web. Use clear, descriptive link text and correct URL types. For images, always consider accessibility and performance: provide appropriate alt text and use responsive techniques to serve the right image for each device.
