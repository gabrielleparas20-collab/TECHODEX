Lesson 8 — Attributes and Global Attributes

Estimated time: 25–40 minutes · Level: Beginner
Back to Lesson 7
Overview Global attributes Custom data attributes ARIA attributes Common element attributes Examples Summary Sources

Overview

Attributes add information to HTML elements. Some attributes are specific to certain elements (for example src on <img>), while global attributes can be used on most elements. This lesson explains global attributes, custom data attributes, ARIA attributes, and common element-specific attributes you will use frequently.

Global attributes

Global attributes are available on most HTML elements. They provide common functionality such as identification, styling hooks, accessibility, and behavior control.

Key global attributes

  • id — unique identifier for an element; useful for anchors, scripting, and labeling.
  • class — one or more class names for styling and selection.
  • title — advisory information shown as a tooltip in some browsers.
  • hidden — indicates the element is not relevant and should not be displayed.
  • style — inline CSS styles (use sparingly; prefer external stylesheets).
  • tabindex — controls keyboard focus order and whether an element is focusable.
  • contenteditable — makes an element editable by the user.
Example 
<div id="intro" class="panel highlight" title="Introduction panel" tabindex="0">
  <p>Welcome to the course.</p>
</div>

Custom data attributes

Custom data attributes allow you to store private data on elements using attributes prefixed with data-. They are accessible in JavaScript via the dataset property and are useful for attaching metadata without polluting global namespaces.

Usage

<div data-user-id="42" data-state="draft">...</div>

<script>
  const el = document.querySelector('[data-user-id]');
  console.log(el.dataset.userId); // "42"
  console.log(el.dataset.state);  // "draft"
</script>
Tip: Keep data attributes for data that is relevant to the client-side script or UI state. Do not store sensitive information in attributes.

ARIA attributes

ARIA attributes enhance accessibility for dynamic or custom UI components. Use ARIA to complement semantic HTML when native elements do not provide the required semantics. Prefer native elements first; use ARIA only when necessary.

Common ARIA attributes

  • role — defines the role of an element (for example role="dialog").
  • aria-label — provides an accessible name when visible text is not available.
  • aria-labelledby — references an element that labels the current element.
  • aria-describedby — references an element that describes the current element.
  • aria-hidden — hides content from assistive technologies.
  • aria-expanded — indicates whether a collapsible element is expanded.
ARIA example 
<button aria-expanded="false" aria-controls="menu1" id="menuBtn">Menu</button>
<nav id="menu1" aria-labelledby="menuBtn">...</nav>
Warning: Incorrect ARIA usage can reduce accessibility. Test with assistive technologies and follow ARIA authoring practices.

Common element attributes

Many elements have attributes specific to their role. A few commonly used ones:

Examples

  • <a href="..." target="_blank" rel="noopener noreferrer"> — links and safe new-tab behavior.
  • <img src="..." alt="..." width="..." height="..."> — images with dimensions and alt text.
  • <input type="..." name="..." value="..." required> — form controls with names and validation.
  • <button type="submit"> — button types for form behavior.
Practical snippet 
<a href="report.pdf" target="_blank" rel="noopener noreferrer" title="Download report (PDF)">Download report</a>

<img src="avatar.jpg" alt="Profile photo of Alex" width="120" height="120">

Examples — putting attributes to work

Interactive card

<article id="card-7" class="card" tabindex="0" data-card-type="lesson" aria-labelledby="card7Title">
  <h3 id="card7Title">Lesson 8: Attributes</h3>
  <p>Short description...</p>
</article>

Accessible toggle

<button id="toggle" aria-expanded="false" aria-controls="panel">Show details</button>
<div id="panel" hidden>Details here</div>

<script>
  const btn = document.getElementById('toggle');
  const panel = document.getElementById('panel');
  btn.addEventListener('click', () => {
    const expanded = btn.getAttribute('aria-expanded') === 'true';
    btn.setAttribute('aria-expanded', String(!expanded));
    panel.hidden = expanded;
  });
</script>
Practice: Add data-* attributes to a UI component and read them from JavaScript to control behavior without adding global variables.

Summary

Attributes are the mechanism for adding metadata, behavior, and accessibility to HTML elements. Use global attributes for common needs, data-* for custom data, and ARIA to fill semantic gaps. Prefer native semantics and keep attributes meaningful, minimal, and secure.
