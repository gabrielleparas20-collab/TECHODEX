Overview

Modern browsers expose APIs that let web pages do more than static markup: draw graphics, fetch data, store state, work offline, and access device features. This lesson introduces several commonly used HTML5 and browser APIs and shows practical snippets to get started safely and accessibly.

Canvas

The <canvas> element provides a drawable region controlled via JavaScript. It's useful for charts, games, and custom graphics. Canvas is pixel-based — use semantic alternatives when content must be accessible (provide text alternatives or ARIA descriptions).

<canvas id="myCanvas" width="400" height="200">Your browser does not support canvas.</canvas>

<script>
  const c = document.getElementById('myCanvas');
  const ctx = c.getContext('2d');
  ctx.fillStyle = '#00aaff';
  ctx.fillRect(10, 10, 150, 100);
</script>
Accessibility: Provide a descriptive caption or an offscreen text alternative for important canvas content.

Fetch API

The Fetch API replaces older XHR patterns with a promise-based interface for network requests. Use fetch() for GET/POST requests and handle errors and timeouts gracefully.

<script>
  async function getData() {
    try {
      const res = await fetch('/api/data');
      if (!res.ok) throw new Error('Network response was not ok');
      const data = await res.json();
      console.log(data);
    } catch (err) {
      console.error('Fetch error:', err);
    }
  }
  getData();
</script>
Tip: Always check res.ok and handle network failures; avoid exposing raw error messages to users.

Web Storage

localStorage and sessionStorage provide simple key/value storage in the browser. Use them for small amounts of non-sensitive state. For larger or structured data, consider IndexedDB.

<script>
  // Save
  localStorage.setItem('theme', 'dark');

  // Read
  const theme = localStorage.getItem('theme');

  // Remove
  localStorage.removeItem('theme');
</script>
Security: Do not store sensitive data (passwords, tokens) in localStorage; prefer secure, short-lived server-side sessions or secure cookies.

Service Workers (intro)

Service workers run in the background and can intercept network requests, enable offline caching, and power push notifications. They require HTTPS and careful lifecycle management.

<script>
  if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js')
      .then(reg => console.log('SW registered', reg))
      .catch(err => console.error('SW registration failed', err));
  }
</script>
Warning: Service workers are powerful; test update and cache strategies to avoid serving stale content.

Geolocation

The Geolocation API provides the user's location with permission. Always request permission at the point of need and provide a fallback if permission is denied.

<script>
  if ('geolocation' in navigator) {
    navigator.geolocation.getCurrentPosition(
      pos => console.log(pos.coords.latitude, pos.coords.longitude),
      err => console.warn('Geolocation error', err),
      { enableHighAccuracy: false, timeout: 5000 }
    );
  }
</script>
Privacy: Explain why you need location and how it will be used; respect user consent and provide controls to disable location features.

Examples — putting APIs together

Simple offline-ready fetch with cache fallback

<script>
async function loadData() {
  try {
    const res = await fetch('/api/items');
    if (!res.ok) throw new Error('Network error');
    const items = await res.json();
    localStorage.setItem('cachedItems', JSON.stringify(items));
    render(items);
  } catch {
    const cached = localStorage.getItem('cachedItems');
    if (cached) render(JSON.parse(cached));
    else showError('Unable to load items.');
  }
}
loadData();
</script>

Canvas + fetch: draw image from network

<canvas id="c" width="400" height="200"></canvas>
<script>
const ctx = document.getElementById('c').getContext('2d');
const img = new Image();
img.crossOrigin = 'anonymous';
img.onload = () => ctx.drawImage(img, 0, 0);
img.src = '/images/photo.jpg';
</script>
Practice: Build a small page that fetches JSON, caches it in localStorage, and renders a simple canvas visualization from the data.

Summary

HTML5 and browser APIs expand what web pages can do: draw graphics, fetch and cache data, store state, run offline, and access device features. Use these APIs responsibly — prioritize accessibility, privacy, and progressive enhancement so features degrade gracefully when unavailable.
